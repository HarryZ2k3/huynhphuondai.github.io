## Context

During my R&D internship at Titan Technology Corporation, I worked on a full-stack product using Popper, an inductive logic programming (ILP) library. The work involved Python and Prolog, alongside a React and Flask application.

## My Contribution

I researched the library's design and architecture, then worked on interfaces that allowed users to interact with its capabilities.

- Designed a command-line tool to run ILP from user input.
- Designed and implemented a web interface using React and Flask.
- Created development tools and technical documentation for future work.
- Managed GitLab merge requests and helped resolve merge conflicts.
- Designed CI/CD workflows with unit tests.

## Working Across Research and Development

The work extended beyond the application interface. Understanding the library, documenting its architecture, and maintaining the team's Git workflow were also part of my contribution.

## Result

My internship contributions covered the full-stack product and the tools and documentation supporting it. The project gave me hands-on experience connecting research software to application development and a shared engineering workflow.
