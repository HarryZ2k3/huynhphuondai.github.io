## Start With The Shape Of The Problem

Before changing settings, I like to write down three things:

- what the user expected
- what happened instead
- when it last worked

That sounds basic, but it prevents a lot of wandering. A clear problem shape makes the next test obvious.

## Check The Simple Layers

I try to move from visible to hidden:

1. Power, cable, Wi-Fi, and account state.
2. Recent updates or changes.
3. Error messages and logs.
4. Scope: one user, one device, one network, or everyone.
5. A small reversible test.

## Leave A Note

The final note is part of the fix. It should explain what changed and what to check first if the same issue returns.
